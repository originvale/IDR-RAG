# Paper result files

These files are the numeric outputs used by the English V38 manuscript. M-087 is the current DPA synchronization and primary paired interval; M-088 is the evaluation-scale state-group analysis used for Table 4. The files are supplied for audit and downstream plotting, not as a claim that every analysis is a confirmatory test.

The primary interval file preserves the cached IDR bootstrap component and the corrected DPA component from M-087. Its summary records the exact seed, tie rule, and confidence interval.
